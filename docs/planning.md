# 《达芬奇密码》交互书 · 规划方案

## Concept

把丹·布朗《达芬奇密码》做成**页上的实体书**：暗舞台中央合上封面 → 持续呼吸浮动 → 悬停微光 → 柔和溶解展开 → 左右羊皮纸跨页。上沿三枚书签 **章节 / 游戏 / 图谱** 夹进纸口，有前/中/后层次。配图统一为 **哥特手抄本 / 页边怪诞画**，上传优先，不强制 Gemini。

## Motif UI

| 元素 | 方向 |
|------|------|
| 舞台 | 深褐乌木 `#120e0b` + 暖色径向光 |

| 字体 | Cormorant Garamond + Noto Serif SC（禁用 Inter/Roboto） |
| 母题文案 | 「符号之下，另有圣杯」 |

## Chapters（剧透克制）

1. 圣殿骑士的阴影 — 双骑士传说与隐秘传承  
2. 卢浮宫之夜 — 展厅、倒伏的身体、未说完的讯息  
3. 密码与数列 — 斐波那契、乱序字母、博物馆暗号  
4. 圣杯的隐喻 — 达芬奇画中的象征语法  
5. 密码筒与逃亡 — 双层筒、巴黎夜逃  
6. 伦敦圣堂 — 圣殿教堂与骑士墓  
7. 罗斯林的回响 — 石刻、血脉传闻（止于门槛）  
8. 真相的门槛 — 追寻者与答案对视（不揭终局）

## Games

| 游戏 | 类型 | 剧情挂钩 |
|------|------|----------|
| 斐波那契的回声 | `fibonacci-sequence` | 左页螺旋点选乱序数字，按斐波那契归位后解锁关键词 |
| 圣杯语法 | `symbol-decode` | 左页点符号读线索，右页三选一裁定；章节先教语法 |
| 密码筒 | `cryptex-rings` | 左页转四环，对照线索拼「玫瑰之下」，与上一局封印呼应 |
| 圣杯符号连线 | `connect` | 玫瑰、圣杯、维特鲁威、双骑士 |

## Character graph

分组：追寻者 · 教会与修会 · 隐秘结社 · 执法。边：师徒、血缘、追捕、信仰、同盟（Teabing 仅作「圣杯学者」，不剧透身份反转）。
