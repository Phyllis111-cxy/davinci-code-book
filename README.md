# 达芬奇密码 · 交互书

哥特手抄本风《达芬奇密码》交互书：合上呼吸浮动 → 溶解打开 → 书签「章节 / 游戏 / 图谱」。

## 开发

```bash
npm install
npm run dev
```

## 交付物

| 路径 | 内容 |

| `docs/prompt-pack.md` | AI Studio / 元宝 / Lovart prompt 包 |
| `src/book.json` | 故事数据（phases / points / 图谱） |
